SIHUMAS - Lapas Kelas III Batulicin
Prototype website kehumasan.

Cara menjalankan:
1. Ekstrak ZIP.
2. Buka index.html dengan Chrome/Edge.
3. Tidak membutuhkan server untuk melihat prototype.

Catatan:
- Data berita/statistik pada prototype masih dummy.
- Form pengaduan hanya simulasi dan menghasilkan nomor tiket lokal.
- Tahap berikutnya dapat dihubungkan ke Google Apps Script/Spreadsheet seperti proyek SISABI.
